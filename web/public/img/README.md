# Images for the sign-in page

Put these two files in this folder. Both are optional: without them the page still works.

| File | What it is | Without it |
|---|---|---|
| `amu-logo.png` | The official Aligarh Muslim University logo (square or round, at least 200 x 200 px, transparent or white background) | An "AMU" badge is shown instead |
| `hero.jpg` | A photograph for the blue sign-in panel, for example a hospital corridor, a doctor with a stethoscope or an ECG monitor (landscape, about 1600 px wide). It is shown under a blue tint so the text stays readable. Use a photo you are allowed to use, such as your own or one from a free-licence site. | The blue gradient with the heart and ECG illustration is shown |

After adding a file, refresh the browser (Ctrl+F5).
